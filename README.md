# leadgen-demos

Демо-прототипы для проактивного B2B-аутрича (Нижний Новгород, пилот «Проактивный ледоген»).

## Что внутри
- `index.html` — универсальное демо: панель «запись + напоминания + отзывы» с переключателем ниш (клиника / автосервис). Все данные **синтетические**.
- Планируется: подпапки `demo-001/`, `demo-002/`, … — персональные демо под конкретные компании.

## Правила приватности
- В репозитории **только синтетические или обезличенные данные**. Никаких реальных названий, адресов, телефонов и тем более ФИО клиентов/пациентов клиентов.
- Персональные демо называются `demo-001`, `demo-002` (без имени компании) и содержат `<meta name="robots" content="noindex">`.
- Привязка «demo-001 = клиника X» хранится только в локальной CRM (`pilot/scoring.csv`), не в публичном коде.
